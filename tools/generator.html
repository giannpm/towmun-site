Générateur de données

Sélectionne toutes les photos d'un dossier à la fois (portfolio ou flash), cet outil les regroupe automatiquement par pièce et génère le code prêt à coller dans portfolio-data.js ou flash-data.js. Rien n'est envoyé nulle part, tout se passe dans ton navigateur.

Type de contenu

Colle ce code à la place du contenu de js/portfolio-data.js ou js/flash-data.js selon ce que tu as choisi, puis redéploie sur Netlify.
